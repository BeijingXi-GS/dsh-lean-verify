# 01 形式化协议：从自然语言问题到 Lean 命题

> 目标：把「一句人话」变成 Lean 能检查的命题，并且保证变换过程可核对。
> 本文件按顺序执行；每一步的产物都要写进最终报告。

---

## 第 1 步：拆出逻辑骨架

先用自然语言把问题改写成标准形式，不要直接写 Lean：

```
∀/∃ <对象及其类型>，若 <假设1> 且 <假设2> …，则 <结论>。
```

- 「对任意正整数 n」→ `∀ n : Nat, 0 < n → …`
> 类型记号：Lean **核心**写 `Nat` / `Int` / `Rat`；`ℕ` / `ℤ` / `ℚ` / `ℝ` / `ℂ` 是 **Mathlib 记号**（`ℝ` 还需要 Mathlib 的 `Real`），需要 `import Mathlib` + `projectDir`。
- 「存在唯一 x 使得」→ `∃! x, …`
- 「当且仅当」→ `↔`，不是 `→`
- 「若…则…」→ `→`；「且」→ `∧`；「或」→ `∨`；「不」→ `¬`
- 隐含的量词：「a、b、c 是三角形的三边」= 三个实数 + 非退化条件（或直接用 Mathlib 的 `Triangle` 结构）

**自检**：把改写后的骨架读回中文，和原题逐字对照；量词顺序变了就是另一个命题。

---

## 第 2 步：选类型

| 原问题 | Lean 类型 | 说明 |
|---|---|---|
| 自然数 / 计数 | `Nat`（Mathlib 记号 `ℕ`） | 减法截断、除法向下取整；负数/差值转 `Int` |
| 整数 | `Int`（Mathlib 记号 `ℤ`） | 数论首选；`dvd`、`%`、`/` 都有明确语义 |
| 有理数 | `Rat`（Mathlib 记号 `ℚ`） | 精确、可 `decide`；适合有限计算 |
| 实数 | `Real`（Mathlib 记号 `ℝ`） | 必须 Mathlib；`ring`/`linarith`/`norm_num` 可用 |
| 复数 | `Complex`（Mathlib 记号 `ℂ`） | Mathlib |
| 点 / 几何对象 | `Real × Real`（坐标，Mathlib 记 `ℝ × ℝ`）或 Mathlib 几何结构 | 坐标化最稳 |
| 序列/列表 | `List α`、`Stream'` | CS 问题常用 |
| 有限集合 | `Finset α` | 计数、求和 |
| 图 | 自定义 `structure` 或 Mathlib `SimpleGraph` | 先自定义最省事 |
| 程序状态 | 自定义 `structure` / 归纳类型 | 写清不变量 |

**规则**：
- 能用离散类型（`Nat`/`Int`/`Rat`）就不用 `Real`，能 `decide` 就别上分析；
- 涉及实数开方、指数、对数、极限，明确写 Mathlib 的名字（`Real.sqrt`、`Real.exp`、`Filter.Tendsto`），不要自己造；
- 类型不确定时先用 `lean_probe` 的 `#check` 试。

---

## 第 3 步：写假设

每个条件都是一个显式参数或蕴含前提：

```lean
theorem name (a b c : ℝ) (ha : 0 < a) (hb : 0 < b) (hab : a + b = 10) :
    a * b ≤ 25 := by
  ...
```

- **不要**把假设写进 `variable` 后忘记在定理里出现；
- 隐含假设（分母 ≠ 0、三角形非退化、n ≥ 1）必须补上，并在报告里标「补充假设」；
- 「实数 x 满足 x² = 2」这种存在性前提，写成 `(hx : x ^ 2 = 2)`；
- 需要唯一性时用 `∃!`。

---

## 第 4 步：Lean 语法最小集

```lean
-- 命题与证明
theorem foo (n : Nat) (h : 0 < n) : n ≠ 0 := by
  intro hn
  rw [hn] at h
  exact Nat.lt_irrefl 0 h

-- 匿名命题（无法做公理审计，正式验证请用命名 theorem）
example : 1 + 1 = 2 := rfl

-- 中间结论
have h1 : 2 + 2 = 4 := by decide
have h2 := Nat.add_comm 1 2

-- 分情况
cases n with
| zero => simp
| succ k => simp

-- 归纳
induction n with
| zero => simp
| succ k ih => simp [ih]

-- 反证
by_contra h
push_neg at h

-- 抽取存在量词
obtain ⟨x, hx⟩ := h

-- 计算链
calc
  f 3 = 3 + f 2 := by rfl
  _ = 3 + (2 + f 1) := by rw [h]
  _ = 6 := by norm_num

-- 定义（递归）
def sumTo : Nat → Nat
  | 0 => 0
  | n + 1 => (n + 1) + sumTo n
```

### 符号对照

| 数学 | Lean |
|---|---|
| ∀ x, P | `∀ x, P` 或 `(x : T) → P` |
| ∃ x, P | `∃ x, P` |
| ∃! x, P | `∃! x, P` |
| P 且 Q | `P ∧ Q` |
| P 或 Q | `P ∨ Q` |
| 非 P | `¬P` |
| P 蕴含 Q | `P → Q` |
| P 当且仅当 Q | `P ↔ Q` |
| x 属于 S | `x ∈ S` |
| a 整除 b | `a ∣ b` |
| a 不整除 b | `¬ a ∣ b` |
| 绝对值 | `|x|` |
| 平方 | `x ^ 2` |
| 求和 | `∑ i ∈ s, f i`（Mathlib） |
| 极限 | `Filter.Tendsto f Filter.atTop (nhds L)` |
| 可微 | `Differentiable ℝ f` |

## 第 5 步：先只验证陈述

写：

```lean
theorem test_statement (a b : ℝ) (h : a + b = 0) : a = -b := by
  sorry
```

然后 `lean_verify`。**预期**：判定 ⚠ 未完成（含 sorry），但**没有编译错误** → 说明陈述本身合法、类型正确。如果这一步就有 `type mismatch` / `unknown identifier`，先修陈述，别写证明。

> 这一步的判定**绝不能**当成「已验证」。它只证明「你写的这句话是合法的 Lean 命题」。

---

## 第 6 步：写证明并迭代

证明结构建议：

1. 先 `intro` 展开量词与前提；
2. 看目标决定策略：算术/判定 → `decide`/`native_decide`/`omega`；代数 → `ring`/`ring_nf`；不等式 → `linarith`/`nlinarith`；定义展开 → `simp [def]`/`rfl`；归纳 → `induction`；
3. 大目标拆 `have`；
4. 每次改完就 `lean_verify`，不要积累一堆错误。

**证明质量自检**：
- 有没有 `sorry` / `admit`？（工具会标）
- 有没有自己 `axiom` 出来一个「显然成立」的引理？（工具会标「条件证明」）
- 有没有用 `native_decide` 代替本该展开的证明？（报告会标可信计算）
- 证明有没有依赖错误的类型转换（`Nat` 转 `Int` 时减法语义变化）？

---

## 第 7 步：判定与陈述保真

工具判定的是 **Lean 命题**。你必须自己核对：

| 检查项 | 问题 |
|---|---|
| 量词 | 「∀」有没有变成「∃」；顺序对不对 |
| 类型 | `Nat`/`Int`/`Rat`/`Real` 选对没有；减法/除法语义 |
| 假设 | 原题条件是否全部出现；有没有多补假设（补了要说明） |
| 结论 | 有没有悄悄弱化（比如只证 `≤` 而原题要 `=`，只证 n≤100） |
| 退化情形 | 空集、零、重合点、除零有没有覆盖 |
| 定义 | 自定义函数/几何对象是否忠实对应原问题 |

**报告里必须写出最终 Lean 陈述原文**（不是转述），并对照上表说明差异。

## 完整示例：验证「前 n 个自然数之和 = n(n+1)/2」

**A. 核心部分（不需要 Mathlib，可验证）：**

```lean
def sumTo : Nat → Nat
  | 0 => 0
  | n + 1 => (n + 1) + sumTo n

theorem sumTo_succ (n : Nat) : sumTo (n + 1) = sumTo n + (n + 1) := by
  simp [sumTo, Nat.add_comm]
```

**B. 闭式公式（需要 Mathlib 的 `nlinarith` 处理非线性项）：**

```lean
import Mathlib

def sumTo : Nat → Nat
  | 0 => 0
  | n + 1 => (n + 1) + sumTo n

theorem sumTo_correct (n : Nat) : 2 * sumTo n = n * (n + 1) := by
  induction n with
  | zero => rfl
  | succ k ih =>
      simp [sumTo]
      nlinarith
```

- A 只用 Lean 核心（`simp` + `omega`），`lean_verify` 预期 ✅ 内核已验证；
- B 需要 Mathlib 工程：`lean_verify projectDir="<mathlib-project>"`；
- 陈述保真：原题「前 n 个自然数之和」= `sumTo n` 的定义；结论 `2 * sumTo n = n*(n+1)` 等价于 `sumTo n = n(n+1)/2`（在整数上避免除法）。报告里要写这个等价说明。
