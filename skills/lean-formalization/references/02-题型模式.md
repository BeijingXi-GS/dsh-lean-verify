# 02 题型模式：不同问题怎么编码

> 每个模式给「编码方式 → 证明策略 → 验证要点」。先选模式，再写代码。
>
> 类型记号：Lean **核心**用 `Nat` / `Int` / `Rat`；`ℕ` / `ℤ` / `ℚ` / `ℝ` 是 **Mathlib 记号**，需要 `import Mathlib` 并给 `lean_verify` 传 `projectDir`。下文中标「核心」的代码不需要 Mathlib，标「Mathlib」的需要。

---

## A. 数论（整除、素数、同余）

**编码（核心；整除 `∣` 在核心可用）**
```lean
-- 整除：a ∣ b 表示 ∃ c, b = a * c
theorem dvd_example (a b : Int) (h : a ∣ b) : a ∣ 2 * b := by
  obtain ⟨c, rfl⟩ := h
  exact ⟨2 * c, by ring⟩

-- 素数用 Mathlib 的 Nat.Prime；核心可自定义：
def IsPrimeN (p : Nat) : Prop := 2 ≤ p ∧ ∀ d, d ∣ p → d = 1 ∨ d = p
```
> `ring` 需要 Mathlib；核心版本把 `exact ⟨2 * c, by ring⟩` 改成 `exact ⟨2 * c, by omega⟩`（`omega` 在核心可用）。`Nat.Prime` 见 Mathlib。
**策略**：`obtain ⟨c, rfl⟩` 展开整除 → `ring`（Mathlib）/`omega`（核心）；同余用 `ZMod n`（Mathlib）或写成 `n ∣ a - b`；大数计算用 `decide`/`native_decide`。
**验证要点**：`Nat` 减法截断（`a - b` 在 `a < b` 时为 0）；整除的方向；`Nat.Prime` 与「大于 1 且只有 1 和自身因子」的定义一致。

## B. 代数恒等式与不等式

**编码（Mathlib：`ℝ` 与 `ring`/`linarith`/`nlinarith`）**
```lean
import Mathlib

example (a b : ℝ) : (a + b) ^ 2 = a ^ 2 + 2 * a * b + b ^ 2 := by ring

example (x y : ℝ) (h : x + y = 10) : x * y ≤ 25 := by nlinarith [sq_nonneg (x - y)]
```
**策略**：恒等式 `ring`/`ring_nf`；线性不等式 `linarith`；非线性 `nlinarith`（常配 `sq_nonneg`、`mul_self_nonneg`）；分式 `field_simp`；取整/自然数 `omega`。
**验证要点**：`ℝ` 需要 Mathlib；不等式方向；等号条件是否要求；`nlinarith` 失败时补平方非负引理。

## C. 组合计数与有限结构

**编码（核心）**
```lean
-- 无 Mathlib：手写递归计数
def countEvens : List Nat → Nat
  | [] => 0
  | x :: xs => (if x % 2 = 0 then 1 else 0) + countEvens xs

theorem countEvens_le (xs : List Nat) : countEvens xs ≤ xs.length := by
  induction xs with
  | nil => simp [countEvens]
  | cons x xs ih => simp [countEvens]; omega
```
**策略**：`List`/`Finset` 递归定义 + `induction` + `simp`；组合恒等式用 `Finset.sum`/`Nat.choose`（Mathlib）+ `omega`/`ring`。
**验证要点**：空列表/空集；边界元素；「恰好一次」用 `Nodup` 或 `Finset` 去重语义。

## D. 几何：坐标化（首选）

竞赛几何优先坐标化：把点写成坐标对，把几何关系写成代数等式，再用 `ring`/`nlinarith`/`norm_num` 证。**实数坐标**（`ℝ`）需要 Mathlib；**整数/有理数坐标 + 具体数值**可以直接用 Lean 核心验证：

```lean
-- 核心版（无 Mathlib）：整数坐标点、共线、垂直
abbrev Pt := Int × Int

def collinear (a b c : Pt) : Prop :=
  (b.1 - a.1) * (c.2 - a.2) = (b.2 - a.2) * (c.1 - a.1)

def perp (a b c d : Pt) : Prop :=
  (b.1 - a.1) * (d.1 - c.1) + (b.2 - a.2) * (d.2 - c.2) = 0

-- 例：A(0,0)、B(2,2)、C(4,4) 共线。注意：decide 前要 unfold 定义
theorem collinear_example : collinear (0, 0) (2, 2) (4, 4) := by
  unfold collinear
  decide

theorem perp_example : perp (0, 0) (1, 0) (0, 0) (0, 1) := by
  unfold perp
  decide
```

一般位置（含参数）的实数坐标题需要 Mathlib：

```lean
-- Mathlib：ℝ、ring、norm_num
import Mathlib

abbrev Pt := ℝ × ℝ

def collinear (a b c : Pt) : Prop :=
  (b.1 - a.1) * (c.2 - a.2) = (b.2 - a.2) * (c.1 - a.1)

def distSq (a b : Pt) : ℝ := (a.1 - b.1) ^ 2 + (a.2 - b.2) ^ 2

noncomputable def mid (a b : Pt) : Pt := ((a.1 + b.1) / 2, (a.2 + b.2) / 2)

def concyclic (a b c d : Pt) : Prop :=
  ∃ (o : Pt) (r : ℝ), distSq o a = r ∧ distSq o b = r ∧ distSq o c = r ∧ distSq o d = r

-- 例：A(0,0)、B(1,1)、C(2,2) 共线
theorem collinear_example' : collinear (0, 0) (1, 1) (2, 2) := by
  norm_num [collinear]

-- 例：一般位置的中点共线（ring 展开）
theorem collinear_midpoint (a b : Pt) : collinear a (mid a b) b := by
  unfold collinear mid
  ring
```
> 实数上的除法/开方定义要标 `noncomputable def`；`midpoint`、`collinear` 等名字 Mathlib 里可能已有，自定义时换名（如 `mid`、`myCollinear`）。
**策略**：
- 共线 → 行列式/斜率等式；
- 平行/垂直 → 向量叉积/点积为 0；
- 共圆 → 存在圆心半径（`∃ o r`），或四点中任意三点不共线 + 对角互补；
- 中点/重心/垂心 → 坐标线性组合；
- 角度相等 → 用 `cos` 或向量点积/叉积表达（避免 `angle` 函数）；
- 具体数值题：`unfold 定义; decide`（核心）或 `norm_num`（Mathlib）；
- 一般位置：`ring` 展开多项式，`nlinarith` 配平方非负。
**验证要点**：退化情形（重合点、三点共线导致「共圆」定义失效）要显式排除或允许；坐标选取要在报告里说明「这是坐标变换，不改变几何性质」；`decide` 前要 `unfold` 自定义谓词，否则会报 `failed to synthesize Decidable`。

## E. 几何：Mathlib `EuclideanGeometry`

只在用户明确要求「用综合几何」或坐标计算爆炸时使用。Mathlib 的 `EuclideanGeometry` 有 `angle`、`dist`、`between`、`Collinear`、`Concyclic`、`Sphere` 等，但引理多、名字长、学习成本高。

**策略**：先用 `lean_probe` 的 `#check` 找引理（或 `exact?`/`apply?`）；把题目拆成「已知引理列表 + 代数收尾」。
**验证要点**：Mathlib 版本与工具链匹配；`import Mathlib` 后首次编译较慢（oleans 加载）。

## F. 计算题 / 数值答案

**编码（核心；大数用 native_decide）**
```lean
-- 具体数值：decide / native_decide / norm_num
theorem compute_1 : (1234 * 5678 : Nat) = 7006652 := by decide
theorem compute_2 : (2 : Nat) ^ 100 = 1267650600228229401496703205376 := by native_decide
theorem pow_mod : (2 : Nat) ^ 100 % 7 = 4 := by decide
```
> `norm_num` 需要 Mathlib；核心用 `decide`（小范围）或 `native_decide`（大数，标「可信计算」）。
**策略**：
1. 先用 `lean_probe` 的 `#eval` 算出候选值（**只是探测，不是证明**）；
2. 再写 `theorem : 表达式 = 值 := by decide / native_decide / norm_num`；
3. 大数/大范围用 `native_decide`（快，但报告标「可信计算」）；
4. 浮点结果不要直接等号比较；转为有理数精确值（`Rat`，Mathlib 记 `ℚ`）或写误差界。

**验证要点**：`Nat` 与 `Int` 的运算语义；`^` 的结合；模运算 `%`；`#eval` ≠ 证明；自定义谓词上的 `decide` 要先 `unfold`（否则 `failed to synthesize Decidable`）。

## G. 计算机程序正确性

**思路**：把程序写成 Lean 的纯函数（或归纳关系），把「正确」写成定理。

```lean
-- 例：列表反转两次等于自身
def rev : List α → List α
  | [] => []
  | x :: xs => rev xs ++ [x]

theorem rev_rev (xs : List α) : rev (rev xs) = xs := by
  induction xs with
  | nil => rfl
  | cons x xs ih => simp [rev, ih]
```
**策略**：
- 规约（spec）：前置条件 `P`、后置条件 `Q`，定理写成 `P s → Q (f s)`；
- 循环：转成尾递归/`Nat` 递归 + 循环不变量；
- 算法：先写「结果满足性质」的定理，再写「复杂度」的函数（显式 `cost` 递归函数 + 不等式）；
- 数据结构不变量：自定义 `structure` + `invariant` 谓词 + 每个操作保持它。

**验证要点**：程序模型是否忠实（副作用、溢出、可变状态、异常）；复杂度模型是「计数模型」不是真实机器时间，要在报告里声明。

## H. 猜想 / 判断题（证伪优先）

```lean
-- 先小范围找反例（探测）
#eval (List.range 1000).filter (fun n => n * n < n)

-- 找到反例后写成定理
theorem counterexample : ¬ (∀ n : Nat, n * n ≥ n) := by
  intro h
  have h2 := h 2
  omega
```
**流程**：
1. 用 `#eval` 枚举小范围（`List.range N`、`Finset.range N`）；
2. 找到反例 → 写 `¬ 命题` 的定理并验证；
3. 找不到 → 尝试证明；证不出就报告「未证明（已测 n ≤ N 无 Nat 反例）」，不要说「成立」。

**验证要点**：反例要具体、可复现；「没找到反例」不是证明。

## I. 选择题 / 多结论题

- 每个选项编码成一个命题，逐个 `lean_verify`；
- 单选题：证明「正确项」并证明其余项为假（或给出反例）；
- 多选题：逐项判定，最后汇总「哪些被证明为真 / 哪些被证伪 / 哪些未定」；
- 填空题：把答案代入原命题验证（`theorem answer : 原式 → 填入 = 答案`）。

---

## J. 算法复杂度（谨慎）

Lean 里没有现成的「O 记号 + 实际运行时间」验证（复杂度的成本模型要自己定义）。可做的是：

- 定义显式的步数函数 `cost : Input → Nat`；
- 证明 `cost x ≤ C * size x * log2 (size x)` 之类的不等式；
- 在报告里明确「这是抽象成本模型，不是机器时间」；不要把「验证了计数上界」说成「验证了实际运行时间」。
